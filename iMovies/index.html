📌 About the Project

What is IMovies? IMovies is a full-stack cinema management system that enables users to browse movies, explore showtimes, select seats, and book tickets seamlessly. Built using the MERN Stack (MongoDB, Express.js, React.js, Node.js), it incorporates secure authentication, real-time seat availability tracking, and an intuitive interface for a smooth and personalized cinema booking experience.
Built With MongoDB · Express.js · React.js · Node.js · JWT · Bootstrap · Socket.io · bcrypt.js

✨ Key Features

🔐
Secure Authentication
JWT-based login, registration, and role-based access control for users and admins.
🎬
Movie Browser
Search and filter movies by genre, language, theatre, location, and date.
💺
Real-Time Seats
Live seat availability tracking using Socket.io for accurate booking.
💳
Ticket Booking
End-to-end booking with payment processing and confirmation.
📊
Admin Panel
Manage movies, theatres, shows, and bookings from a dedicated dashboard.
📱
Responsive UI
Mobile-friendly interface built with React.js and Bootstrap.
