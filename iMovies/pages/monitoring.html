📊 7. Monitoring & Optimization

Scalable & Production-Ready Optimize MongoDB queries with indexing, enable centralized error handling, apply pagination, and refactor services for maintainability and scalability.

📑 MongoDB Indexing

Why Indexing Matters Proper indexes dramatically reduce query time for movie search, show filtering, and booking history lookups — especially as data grows.
Indexes by Collection 
// Movie Search Index
movieSchema.index({ title: 'text', description: 'text' });
movieSchema.index({ genre: 1, language: 1, releaseDate: -1 });

// Show Filtering Index
showSchema.index({ movie: 1, theatre: 1, date: 1 });
showSchema.index({ date: 1, time: 1 });

// Booking History Index
bookingSchema.index({ user: 1, createdAt: -1 });
bookingSchema.index({ show: 1, status: 1 });

// Seat Availability Index
seatSchema.index({ show: 1, isBooked: 1 });
CollectionIndex Field(s)Use Case
Moviestitle (text), genre, languageFull-text search, genre/language filter
Showsmovie, theatre, date, timeShow listing by movie and location
Bookingsuser, createdAtUser booking history (sorted)
Seatsshow, isBookedReal-time seat availability queries

🚨 Centralized Error Handling

middleware/errorHandler.js 
const errorHandler = (err, req, res, next) => {
  let statusCode = res.statusCode !== 200 ? res.statusCode : 500;
  let message    = err.message || 'Internal Server Error';

  // Mongoose – CastError (invalid ObjectId)
  if (err.name === 'CastError') {
    statusCode = 404;
    message    = `Resource not found`;
  }

  // Mongoose – Duplicate Key
  if (err.code === 11000) {
    statusCode = 400;
    const field = Object.keys(err.keyValue)[0];
    message    = `${field} already exists`;
  }

  // Mongoose – Validation Error
  if (err.name === 'ValidationError') {
    statusCode = 400;
    message    = Object.values(err.errors).map(e => e.message).join(', ');
  }

  // JWT Error
  if (err.name === 'JsonWebTokenError') {
    statusCode = 401;
    message    = 'Invalid token';
  }

  res.status(statusCode).json({
    success: false,
    message,
    ...(process.env.NODE_ENV === 'development' && { stack: err.stack }),
  });
};

module.exports = errorHandler;
server.js – Register error handler (last middleware) 
const errorHandler = require('./middleware/errorHandler');

// ... routes ...

app.use(errorHandler);

📄 Pagination

Paginated Movie Listing 
exports.getMovies = async (req, res) => {
  const page  = parseInt(req.query.page)  || 1;
  const limit = parseInt(req.query.limit) || 12;
  const skip  = (page - 1) * limit;

  const query = { isActive: true };
  if (req.query.genre)    query.genre    = req.query.genre;
  if (req.query.language) query.language = req.query.language;

  const [movies, total] = await Promise.all([
    Movie.find(query).sort({ releaseDate: -1 }).skip(skip).limit(limit),
    Movie.countDocuments(query),
  ]);

  res.json({
    success:     true,
    data:        movies,
    pagination: {
      page,
      limit,
      total,
      pages: Math.ceil(total / limit),
    },
  });
};

✅ Optimization Checklist

  • Add MongoDB indexes for all frequently queried fields.
  • Use pagination for movie listings and booking logs.
  • Enable Express rate limiting on all API routes.
  • Implement centralized error handler as last Express middleware.
  • Use morgan for HTTP request logging in development and production.
  • Separate concerns — controllers, services, models, routes in distinct folders.
  • Cache frequently accessed data (e.g., movie list) using Redis (optional).
  • Use React.memo and lazy loading for large UI components.
  • Compress responses with Express compression middleware.
  • Enable GZIP on the production server or CDN layer.
