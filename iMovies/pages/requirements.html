🖥️ System Requirements

Prerequisites for Development To ensure smooth development, deployment, and usage of IMovies, certain system prerequisites must be met. These are categorized into software, setup, and hardware specifications.

💿 1. Software Requirements

Essential tools and platforms required to develop, test, and run the application.
SoftwareVersionPurposeDownload
Operating System Win 10/11, macOS, Linux Cross-platform development environment —
Node.js v16 or above Runtime for backend logic and API routing nodejs.org ↗
npm v8 or above Package manager for all dependencies Bundled with Node.js
React.js v18+ JavaScript library for building dynamic UIs reactjs.org ↗
MongoDB v6+ NoSQL database for all application data mongodb.com ↗
Express.js v4+ Lightweight framework for RESTful APIs expressjs.com ↗
Git Latest Version control and collaboration git-scm.com ↗
Postman Latest Testing and debugging REST APIs postman.com ↗
Visual Studio Code Latest Preferred code editor with terminal and Git code.visualstudio.com ↗
Browser Chrome / Firefox (Latest) Rendering and testing the UI in real time —
