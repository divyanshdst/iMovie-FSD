✅ Server-Side Validation

Example – Booking Validation 
const validateBooking = (req, res, next) => {
  const { showId, seats } = req.body;

  if (!showId) {
    return res.status(400).json({ message: 'Show ID is required' });
  }

  if (!seats || !Array.isArray(seats) || seats.length === 0) {
    return res.status(400).json({ message: 'At least one seat must be selected' });
  }

  if (seats.length > 10) {
    return res.status(400).json({ message: 'Maximum 10 seats per booking' });
  }

  next();
};

// Apply to route
router.post('/', protect, validateBooking, createBooking);

🎯 Frontend Form Validation

Registration Form Validation 
const validateRegister = (values) => {
  const errors = {};

  if (!values.name || values.name.trim().length < 2) {
    errors.name = 'Name must be at least 2 characters';
  }

  if (!values.email || !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(values.email)) {
    errors.email = 'Enter a valid email address';
  }

  if (!values.password || values.password.length < 6) {
    errors.password = 'Password must be at least 6 characters';
  }

  if (values.password !== values.confirmPassword) {
    errors.confirmPassword = 'Passwords do not match';
  }

  return errors;
};

🏁 Test Completion Criteria

  • All auth endpoints return correct status codes and messages.
  • Admin routes reject non-admin users with 403 Forbidden.
  • Booking prevents double-seat reservation correctly.
  • Search and filter returns accurate, relevant results.
  • Payment success flow updates booking status to confirmed.
  • Cancellation updates seat availability in real time.
  • All form fields show proper validation errors.
  • UI renders correctly on mobile (375px) and desktop (1280px+).
